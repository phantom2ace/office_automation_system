## 📖 How To Use Each Feature

### Email Configuration (2 minutes)
```
1. Admin → 📧 Email Configuration
2. Enter SMTP settings (Gmail, Office 365, etc.)
3. Click "Test Email"
4. Enable notification types
5. Done!
```

### Create Automation Rule (3 minutes)
```
1. Admin → ⚙️ Automation
2. Click "➕ New Rule"
3. Name: "Escalate Overdue Tasks"
4. When: Task becomes overdue
5. Then: Escalate to manager
6. Save Rule
7. Rule now auto-executes
```

### Process Payroll (5 minutes)
```
1. Admin → 💳 Payroll
2. Select employee
3. Select month
4. Click "📊 Calculate Payroll"
5. Verify calculations
6. Record saved as Processed
```

### Upload Document Version (1 minute)
```
1. Documents → Select document
2. Click "Upload New Version"
3. Select file
4. Add comment
5. Upload
```

### Send Message (30 seconds)
```
1. Messages → Search user
2. Click conversation
3. Type message
4. Press Enter
5. Message sent!
```

## 🔍 Testing Each Feature

### Email Test
1. Go to Email Configuration
2. Click "Test Email"
3. Enter your email
4. Check inbox for test email
5. If works → Email system ready!

### Automation Test
1. Create rule: "Task overdue → Escalate"
2. Create task with past due date
3. Check Automation Execution logs
4. Should show rule executed
5. If works → Automation ready!

### Payroll Test
1. Go to Payroll page
2. Configure salary (Base: 50000, Allowances: 5000)
3. Click Check In
4. Click Check Out
5. Admin: Select employee & month
6. Click Calculate Payroll
7. Verify: Gross = Base + Allowances
8. If correct → Payroll ready!

### Document Test
1. Create document
2. Upload file (v1 created)
3. Upload new file (v2 created)
4. Click "Version History"
5. See both versions listed
6. If works → Versioning ready!

### Message Test
1. Open Messages
2. Search for user
3. Click conversation
4. Type test message
5. Other user should see it
6. If received → Messaging ready!

## 🚨 Important Notes

### Email Configuration
- Use **app-specific password** (not regular password) for Gmail
- SMTP Port: 587 for TLS, 465 for SSL
- Test email button verifies settings work

### Payroll Processing
- Must configure salary BEFORE processing payroll
- Attendance (check-in/out) must be tracked for hours
- Tax % and deductions affect net salary calculation

### Automation Rules
- Rule executes automatically when trigger event happens
- Check logs to verify rule is working
- Can enable/disable rule anytime

### Access Control
- Employee directory: Admin & HR only
- User Management: Admin only
- Payroll: HR & own employee only
- Help Desk: All authenticated users

### Help Desk Tickets
- Uses email automation for notifications
- Agent can escalate tickets
- Full work history tracked
