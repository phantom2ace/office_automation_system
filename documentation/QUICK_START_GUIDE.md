# 🎯 Department-Specific Features - Quick Start Guide

## System is Now Personalized! 🎉

Your office automation system now adapts to each user's **role** and **department**.

---

## 🏢 What Each Department Gets

### 💰 Finance Department
**Exclusive Tools:**
- **🧮 Calculator** - Advanced financial calculations
  - GST Calculator (VAT for different rates)
  - Discount Calculator
  - Profit/Loss Calculator
  - Percentage Change Calculator
- **💰 Finance Module** - Expense tracking and budgeting

**Access**: Navigate to **Calculator** in dashboard or sidebar

---

### 🆘 IT Department  
**Exclusive Tools:**
- **🆘 Help Desk** - Customer support ticket system
  - Submit IT problems (hardware, software, network, VPN, etc.)
  - Track ticket status
  - For IT Managers: Assign and resolve tickets
  - For Users: Submit and monitor tickets

**Access**: Navigate to **Help Desk** in dashboard or sidebar

**How to submit a ticket:**
1. Go to Help Desk page
2. Fill in issue title and description
3. Select category (Hardware, Software, Network, Email, Printer, VPN)
4. Choose priority (Low, Medium, High, Urgent)
5. Click "Submit Ticket"
6. Get automatic ticket number
7. Track status in "My Support Tickets"

---

### 👥 HR Department
**Exclusive Tools:**
- **👥 Employee Management** - View employee directory
- **🏖️ Leave Management** - Manage leave requests
- **⭐ Performance** - Performance reviews and ratings

---

### 📊 Sales Department
**Exclusive Tools:**
- **📊 Analytics** - Sales data and trends
- **⭐ Performance** - Sales performance tracking
- **📈 Reports** - Custom reports

## 📱 Common Tasks

### 🆘 I'm in IT and Need to Report a Technical Issue
```
Dashboard → Help Desk → Create Support Ticket
Fill details → Submit → Get Ticket Number → Track Status
```

### 💰 I'm in Finance and Need to Calculate GST
```
Dashboard → Finance Calculator 
OR
Sidebar → Calculator → Select GST Calculator
Enter Amount & Rate → Calculate
```

### 👥 I'm in HR and Need to Approve Leaves
```
Dashboard → Leave Management
OR
Sidebar → Leaves → Review Pending Requests
Approve or Reject → Add Comments → Save
```

## 🔐 Privacy & Security

- **Users only see their own department data**
- **Admins can see everything** (for oversight)
- **Help Desk tickets are isolated** (only IT manages)
- **Financial data locked to Finance dept**
- **HR data locked to HR dept**
- **Sales metrics locked to Sales dept**

## 📞 Help Desk Categories

When submitting a ticket, choose from:
- 🖥️ **Hardware Issue** - Computer, printer, peripherals
- 💻 **Software Issue** - Application, installation, licensing
- 🌐 **Network Issue** - Internet, connectivity, VPN
- 📧 **Email/Account** - Account access, email setup
- 🖨️ **Printer Issue** - Printing problems, drivers
- 🔐 **VPN/Remote Access** - Remote work, VPN connection
- ❓ **Other** - Miscellaneous IT issues

---

## 📊 Help Desk Ticket Workflow

```
User Submits Ticket
        ↓
IT Manager Reviews
        ↓
Assigns to IT Staff
        ↓
Staff Works on Issue
        ↓
Changes Status: Open → In Progress → Closed
        ↓
Adds Resolution Notes
        ↓
User Notified of Resolution
```

## 🧮 Available Calculations

**Finance Calculator includes:**

1. **GST Calculator**
   - Input: Amount, GST Rate
   - Output: GST Amount, Total Price

2. **Discount Calculator**
   - Input: Original Price, Discount %
   - Output: Discount Amount, Final Price

3. **Profit/Loss Calculator**
   - Input: Cost Price, Selling Price
   - Output: Profit/Loss Amount & %

4. **Percentage Change**
   - Input: Old Value, New Value
   - Output: % Change (increase/decrease)

- 🟢 **Green** = Closed (resolved)

**Priority Colors:**
- 🔵 **Blue** = Low
- 🟡 **Yellow** = Medium
- 🟠 **Orange** = High
- 🔴 **Red** = Urgent

## 🆘 Troubleshooting

**I don't see my department's tool?**
- Check you're logged in with correct account
- Refresh page (F5)
- Verify your department in profile

**Help Desk ticket not showing?**
- Only IT department can see Help Desk
- Check if you're in IT department
- Verify account role

**Calculator missing?**
- Only Finance department has access
- Check if logged in as Finance user
- Switch accounts if needed
