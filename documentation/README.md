# Office Automation System

A full office automation system built with Node.js, Express, SQLite, and Vanilla JavaScript.

## Features
- User authentication
- Department-based task automation
- Task acceptance and decline with reasons
- Internal messaging
- Document management
- Scheduling and reminders
- Workflow automation
- Analytics dashboard
- Finance management
- Inventory management

## How to Run
1. Clone repository
2. Open backend folder
3. Run `npm install`
4. Run `node server.js`
5. Open frontend HTML files in browser
